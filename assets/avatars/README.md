# Ilustrações do avatar

Coloque aqui os PNG/WebP finais seguindo `docs/ARTE.md` e rode `npm run assets`.

```
{categoria}/{assetId}/{corpo|all}/{camada}[.mask|.shade][@2x].webp
body/base/body-b/body.mask.webp
outfit/tunic-joseph/body-a/upper_outfit.webp
outfit/tunic-joseph/body-a/upper_outfit@2x.webp
```

Arquivos inválidos (tamanho, sem transparência, nome ou camada errados) fazem o comando falhar.
